# 上河築城

以中國古代為背景的城鎮建設遊戲（Godot 4.6，GDScript）。城建部分參考 Cities: Skylines，貨運經營參考 OpenTTD。畫面全部由程式繪製，配色取自青綠山水與界畫。

## 啟動

- 雙擊 `開始遊戲.cmd` 開始遊戲，或雙擊 `開啟編輯器.cmd` 在 Godot 編輯器中開啟專案。
- 也可以用任一 Godot 4.6 開啟 `project.godot`。

## 玩法

1. **修路**：道路必須連到縣衙，而且要在轄境之內（沿路距離，品級越高轄境越大）。
2. **劃分區**：民居、市肆、作坊須臨路，農田離路三格內即可。頂欄四條需求柱是民、市、工、農。
3. **民政**：水井、市集讓茅舍升為瓦屋；教化、信仰或娛樂，加上地價與奢侈品（綢緞、瓷器、茶），讓瓦屋升為宅院。
4. **糧食**：秋收最豐，冬季幾乎沒有收成，要建糧倉存糧。
5. **產業與貨運**：伐木場、採石場、鐵礦、茶園、瓷窯等。旁邊建驛站或碼頭，再用「開闢路線」接到城中或外邑（洛陽、揚州、成都）賣貨。路途越遠出價越高，但行程太久會折價。
6. **品級**：人丁增長後，依序由村晉升為鎮、縣、州、府、京。每升一級會解鎖新建築、政令和車船。
7. **災異**：火災、疫病、盜匪、洪水、旱災，分別用望火樓、醫館、捕快房、「興修水利」和存糧來應對。

## 介面

- **詔令**（左上）：依序列出接下來三項目標，達成就賞銀，從鑿第一口井一直到晉升京師，共十八項。
- **小地圖**（右下）：點擊或拖曳可移動視野。
- **統計**：用折線圖呈現人丁、銀兩、民心、貿易的逐月走勢。
- **懸停提示**：滑鼠停在建築或車船上，會顯示居民數、民心、載貨、是否通達。
- **點選車船**：查看路線、狀態、載貨，也可以直接賣出。
- **配樂**：以撥弦合成即時生成五聲音階的古琴風配樂，建造、詔令、晉升、災異各有音效。頂欄「樂」可以關掉配樂。

## 操作

| 按鍵 | 作用 |
|---|---|
| 左鍵 | 使用工具／選取；道路可拖曳成線，分區與拆除可拖曳成片 |
| 右鍵拖曳、中鍵 | 平移 |
| 滾輪 | 縮放 |
| WASD／方向鍵 | 平移 |
| 空白鍵 | 暫停 |
| 1／2／3 | 調整速度 |
| B | 拆除 |
| Esc | 取消 |
| F5／F9 | 存檔／讀檔 |

## 程式結構

| 檔案 | 內容 |
|---|---|
| `scripts/defs.gd` | 靜態資料：建築、貨物、品級、政令、車船 |
| `scripts/game.gd` | 模擬：經濟、服務覆蓋、升級、災異、貨運路線、存檔 |
| `scripts/worldgen.gd` | 地形生成 |
| `scripts/art.gd` | 程式繪製的屋宇、樹木、山巒、車船 |
| `scripts/batch.gd` | 把每一塊地圖合併成一個網格繪製 |
| `scripts/world_view.gd` | 分塊地面、按對角線排序的物件、行人、煙火天氣、資料圖層 |
| `scripts/main.gd` | 攝影機、工具輸入、游標預覽 |
| `scripts/ui.gd` | 介面、詔令、小地圖、統計圖 |
| `scripts/audio.gd` | 程式合成的配樂與音效 |

自動測試：`Godot --path . -- --shots=<資料夾> --auto` 會自動建一座城並輸出截圖；改用 `--uitest` 則會模擬操作各種工具與視窗。
