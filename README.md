# 水村山郭

以中國古代為背景的城鎮建設遊戲（Godot 4.6，GDScript）。城建部分參考 Cities: Skylines，貨運經營參考 OpenTTD。畫面全部由程式繪製，配色取自青綠山水與界畫。

## 啟動

- 雙擊 `開始遊戲.cmd` 開始遊戲，`開發模式.cmd` 直接進入測試城，`開啟編輯器.cmd` 在 Godot 編輯器中開啟專案。
- 三個入口都交給 `scripts/tools/launch.cmd` 找 Godot 4.6，依序找：環境變數 `GODOT`；遊戲資料夾或上一層的 `Godot*.exe`；PATH 上的 `godot`；舊機器上的 `D:\zoo\...`；專案放在 WSL 裡時，改用 WSL 中 `.toolchains` 的 Linux 版（WSLg 開窗、D3D12 走顯卡）。都找不到時會提示去哪下載。
- 最簡單的做法：從 Godot 官網下載 4.6.1 Windows 版，把 `Godot_v4.6.1-stable_win64.exe` 放進遊戲資料夾。
- 也可以用任一 Godot 4.6 開啟 `project.godot`。

## 玩法

1. **修路**：道路必須接上縣衙，而且要在轄境之內。轄境是以縣衙為圓心的一圈（村 18 格、鎮 24、縣 30、州 38、府 48、京 70），修路、劃區、放建築時地圖上會畫出紅色虛線圈；圈外的路標琥珀色，沒接上縣衙的路標紅色。路修過水面就是橋；橋只能筆直跨水，不能在水上交會、轉彎或兩座並排，岸上的路也不能從側面接到橋身。通航水面上的平橋是高腳木橋，船從橋下過；福船過橋前放倒桅杆。晉鎮以後，兩旁房舍興旺的土路會由官府出資自動鋪成石板（每月至多十二格、每格十兩，府庫須有三百兩以上）。道路分類裡的「填土」可把水面填回陸地（運河每格十兩、河湖每格三十兩）。
2. **劃分區**：民居、市肆、作坊須緊貼道路（四邊之一，斜角不算），農田離路三格內即可；水井、醫館、私塾等設施與產業兩格內有路就能運作。放建築時若不會通達，游標旁會寫明原因（附近沒有路／路沒接到縣衙／在轄境之外）並框出需要有路的範圍。頂欄四條需求柱是民、市、工、農。
3. **民政**：水井、市集讓茅舍升為瓦屋；教化、信仰或娛樂，加上地價與奢侈品（綢緞、瓷器、茶），讓瓦屋升為宅院。
4. **糧食**：秋收最豐，冬季幾乎沒有收成，要建糧倉存糧。一倍速下一日一秒、一月三十秒、一年六分鐘。
5. **產業與貨運**：伐木場、採石場、鐵礦、茶園、瓷窯等。旁邊建驛站或碼頭，再用「開闢路線」接到城中或外邑（洛陽、揚州、成都）賣貨。路途越遠出價越高，但行程太久會折價。
6. **品級**：人丁增長後，依序由村晉升為鎮、縣、州、府、京。每升一級會解鎖新建築、政令和車船。
7. **災異**：火災、疫病、盜匪、洪水、旱災，分別用望火樓、醫館、捕快房、「興修水利」和存糧來應對。

## 介面

- **詔令**（左上）：依序列出接下來三項目標，達成就賞銀，從鑿第一口井一直到晉升京師，共十八項。
- **小地圖**（右下）：點擊或拖曳可移動視野。
- **統計**：用折線圖呈現人丁、銀兩、民心、貿易的逐月走勢。
- **懸停提示**：滑鼠停在建築或車船上，會顯示居民數、民心、載貨、是否通達。
- **點選車船**：查看路線、狀態、載貨，也可以直接賣出。
- **冊頁**：點選建築會顯示小景、升級路線與「還缺」清單；清單上的〔去建〕可直接拿起對應工具。
- **警示籤**：失火、疫病、斷路、缺水、無原料、缺工的建築上方掛紙籤，點擊即打開冊頁；全景時同一街區合併成一張帶數字的籤。
- **詔令進度**：可計數的詔令附進度條，達成時蓋「准」字朱印。
- **邸報**：帶定位圖示的消息可點，鏡頭會移到事發地點。
- **格局**：特定建築擺在一起即成格局（虹橋、瓦子、漕運、四合院、梵剎、衙署、桑基魚塘、茶馬、官窯），外觀改變、每月另有收入，並收入案牘的「圖鑑」頁。
- **長卷**：每次晉升自動把城畫成一卷手卷，案牘「長卷」頁也可隨時「繪今貌」。卷由右往左為引首（城名＋品級＋圖）、畫心（主城加上城外產業，絹本調色、段與段以雲煙相接，左端落款鈐印）、拖尾（白話題跋，記開城、晉升、格局、商路、災異與今貌）。看卷時先播開卷動畫，再以滾輪、拖曳、方向鍵平移，可存為 PNG。
- **介面縮放**：介面依視窗大小等比放大，字型以放大後的大小重繪，大螢幕上依然清晰；首次開啟時視窗約佔螢幕八成五。系統選單「介面大小」可再調為 85%、100%、115%、130%，設定會保存。
- **貨物圖示**：糧、魚、木、石、鐵、絲、茶、器物、綢緞、瓷器各有一枚墨線圖示，倉廩頁、冊頁的產出耗用、車船載貨、商路、建造提示裡都標在名稱前。
- **換季**：入春、夏、秋、冬時，日期下垂下一張紙籤，寫節氣與它的第一候（《禮記·月令》：立春東風解凍、立夏螻蟈鳴、立秋涼風至、立冬水始冰）和一句提醒；地圖由左往右漸染成新的季節。
- **動態**：拆除時屋塌留殘垣、換季由左往右漸染、晉升時轄境圈外擴、警示籤輕擺、大事橫幅如捲軸展開、天頭數字滾動。系統選單「動態」可切換「全／簡」，「簡」只留回饋類動畫，設定會保存。
- **配樂**：以撥弦合成即時生成五聲音階的古琴風配樂，建造、詔令、晉升、災異各有音效。頂欄「樂」可以關掉配樂。

## 操作

| 按鍵 | 作用 |
|---|---|
| 左鍵 | 使用工具／選取；道路可拖曳成線，分區與拆除可拖曳成片 |
| 右鍵拖曳、中鍵 | 平移 |
| 滾輪 | 縮放 |
| WASD／方向鍵 | 平移 |
| 空白鍵 | 暫停 |
| 1／2／3 | 調整速度 |
| B | 拆除 |
| Esc | 取消 |
| F5／F9 | 存檔／讀檔 |

    │   └── worldgen.gd          地形生成

    │   ├── world_view.gd        分塊地面、物件、行人、煙火天氣、建造與倒塌動畫、換季漸染、資料圖層

## 打包

`export_presets.cfg` 已設好 Windows 版：單一執行檔（遊戲資料內嵌）、Compatibility（OpenGL 3.3）算圖、內嵌程式圖示 `icon.ico`。在本目錄執行：

```
godot --headless --path . --export-release "Windows Desktop" ../發行/水村山郭/水村山郭.exe
```

輸出約 140 MB，別人雙擊即可遊玩，不需安裝 Godot。`../發行/水村山郭/說明.txt` 是給玩家的簡短說明；整個資料夾壓成 `../發行/水村山郭.zip` 即可分享。需先安裝 Godot 4.6.1 的匯出範本。

## 測試與錄影

在專案目錄下以 Godot 4.6 執行：

| 指令 | 作用 |
|---|---|
| `godot --headless --path . -- --test` | 規則測試：路、橋、轄境、石拱橋、數字、大事記與存讀檔，不開視窗，約五秒。`--test=bridge,reach` 只跑指定幾項 |
| `godot --headless --path . --fixed-fps 30 -- --autoplay` | 不開視窗跑完機器人一局，約一分鐘，用來核對模擬結果 |
| `godot --path . -- --dev --city=auto` | 開發模式：跳過開場，直接進入自動建好的測試城；F6 加銀萬兩、F7 晉升一級、F8 過一月、Shift+F8 過一年、F10 重建測試城。Windows 上雙擊 `開發模式.cmd` |
| `godot --path . -- --shots=<資料夾> --auto` | 自動建城並輸出截圖 |
| `godot --path . -- --shots=<資料夾> --uitest` | 模擬操作各種工具與視窗，並驗證存讀檔 |
| `godot --path . -- --shots=<資料夾> --scroll` | 自動建城並繪一卷長卷，輸出長卷圖、看卷畫面、卷匣頁，並驗證存圖與存讀檔 |
| `godot --path . --write-movie out.avi --fixed-fps 30 -- --autoplay` | 機器人玩一局並錄成影片（約四分鐘） |

測試、錄影與開發模式存檔都寫到 `user://test_save.dat`，不會蓋掉玩家的存檔。
