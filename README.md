# 上河築城

以中國古代為背景的城鎮建設遊戲（Godot 4.6，GDScript）。城建部分參考 Cities: Skylines，貨運經營參考 OpenTTD。畫面全部由程式繪製，配色取自青綠山水與界畫。

## 啟動

- 雙擊 `開始遊戲.cmd` 開始遊戲，或雙擊 `開啟編輯器.cmd` 在 Godot 編輯器中開啟專案。
- 也可以用任一 Godot 4.6 開啟 `project.godot`。

## 玩法

1. **修路**：道路必須連到縣衙，而且要在轄境之內（沿路距離，品級越高轄境越大）。
2. **劃分區**：民居、市肆、作坊須臨路，農田離路三格內即可。頂欄四條需求柱是民、市、工、農。
3. **民政**：水井、市集讓茅舍升為瓦屋；教化、信仰或娛樂，加上地價與奢侈品（綢緞、瓷器、茶），讓瓦屋升為宅院。
4. **糧食**：秋收最豐，冬季幾乎沒有收成，要建糧倉存糧。
5. **產業與貨運**：伐木場、採石場、鐵礦、茶園、瓷窯等。旁邊建驛站或碼頭，再用「開闢路線」接到城中或外邑（洛陽、揚州、成都）賣貨。路途越遠出價越高，但行程太久會折價。
6. **品級**：人丁增長後，依序由村晉升為鎮、縣、州、府、京。每升一級會解鎖新建築、政令和車船。
7. **災異**：火災、疫病、盜匪、洪水、旱災，分別用望火樓、醫館、捕快房、「興修水利」和存糧來應對。

## 介面

- **詔令**（左上）：依序列出接下來三項目標，達成就賞銀，從鑿第一口井一直到晉升京師，共十八項。
- **小地圖**（右下）：點擊或拖曳可移動視野。
- **統計**：用折線圖呈現人丁、銀兩、民心、貿易的逐月走勢。
- **懸停提示**：滑鼠停在建築或車船上，會顯示居民數、民心、載貨、是否通達。
- **點選車船**：查看路線、狀態、載貨，也可以直接賣出。
- **格局**：特定建築擺在一起即成格局（虹橋、瓦子、漕運、四合院、梵剎、衙署、桑基魚塘、茶馬、官窯），外觀改變、每月另有收入，並收入案牘的「圖鑑」頁。
- **配樂**：以撥弦合成即時生成五聲音階的古琴風配樂，建造、詔令、晉升、災異各有音效。頂欄「樂」可以關掉配樂。

## 操作

| 按鍵 | 作用 |
|---|---|
| 左鍵 | 使用工具／選取；道路可拖曳成線，分區與拆除可拖曳成片 |
| 右鍵拖曳、中鍵 | 平移 |
| 滾輪 | 縮放 |
| WASD／方向鍵 | 平移 |
| 空白鍵 | 暫停 |
| 1／2／3 | 調整速度 |
| B | 拆除 |
| Esc | 取消 |
| F5／F9 | 存檔／讀檔 |

## 專案結構

```
skylines/
├── project.godot、main.tscn     Godot 專案與主場景
├── 開始遊戲.cmd、開啟編輯器.cmd  Windows 啟動捷徑
├── fonts/                       思源宋體、霞鶩文楷（OFL 授權，授權檔同目錄）
├── docs/                        設計文件
│   ├── 介面改造計畫.md           介面方向、已完成項目與待辦
│   └── 組合玩法研究.md           格局玩法的參考案例、已實作的格局
└── scripts/
    ├── main.gd                  攝影機、工具輸入、游標預覽、自動截圖與介面測試
    ├── sim/                     模擬（不涉畫面）
    │   ├── defs.gd              靜態資料：建築、貨物、品級、政令、車船、詔令、格局
    │   ├── game.gd              經濟、服務覆蓋、升級、災異、貨運、格局偵測、存檔
    │   └── worldgen.gd          地形生成
    ├── view/                    地圖畫面
    │   ├── art.gd               程式繪製的建築、人物、車船、格局點綴
    │   ├── batch.gd             把每一塊地圖合併成一個網格繪製
    │   └── world_view.gd        分塊地面、物件、行人、煙火天氣、建造動畫、資料圖層
    ├── ui/                      介面
    │   ├── ui.gd                天頭地頭、建造托板、冊頁、案牘、圖鑑、詔令、邸報、開場
    │   └── ui_art.gd            介面畫具：色票、字型、紙紋木紋、圖示
    ├── audio/
    │   └── audio.gd             程式合成的配樂與音效
    └── tools/
        └── autoplay.gd          自動遊玩一局，供錄製示範影片
```

## 測試與錄影

在 `skylines/` 目錄下以 Godot 4.6 執行：

| 指令 | 作用 |
|---|---|
| `godot --path . -- --shots=<資料夾> --auto` | 自動建城並輸出截圖 |
| `godot --path . -- --shots=<資料夾> --uitest` | 模擬操作各種工具與視窗，並驗證存讀檔 |
| `godot --path . --write-movie out.avi --fixed-fps 30 -- --autoplay` | 機器人玩一局並錄成影片（約四分鐘） |
