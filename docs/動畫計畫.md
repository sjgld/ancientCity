# 動畫計畫

研究報告（現況盤點、34 項建議、分批、技術方案、三段示範）：https://claude.ai/artifact/FML4vxdTtJ6Ejs94CzEafk

## 原則

- 動作只用五種材料本來會有的：墨（勾勒、暈開）、紙（展開、捲起、輕擺）、印（落下）、煙雲（升、散）、木（推拉、抽起）。不用金色粒子、發光、閃白、震屏、Q 彈。
- 三個時鐘（`scripts/view/motion.gd`）：介面時鐘用實際時間；世界時鐘隨倍速、暫停即停；環境時鐘暫停時以三成速度慢動。
- 系統選單「動態：全／簡」，存於 `user://settings.cfg`。「簡」只留回饋類動畫。
- 動畫只讀模擬，不用 `Game.rng`。改完跑 `--autoplay`，結果須與基準一致（見 `docs/介面改造計畫.md`「驗證方式」）。
